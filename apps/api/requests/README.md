# Requests

This module is not a part of `api` as in `src`, rather a helpful tool/utility.

## http.sh
This script makes a request to the HTTP server. You can invoke this script, pass an endpoint name as the first argument, and optionally, other arguments, which will be passed along to the endpoint, if it's a POST endpoint.

## grpc.sh
This script makes a request to the GRPC server. You can invoke this script, pass an endpoint name as the first argument, and optionally, other arguments, which will be passed along to the endpoint, if it's a POST endpoint.

## grpc/ and http/
These directories contain the request files for their respective protocols.
